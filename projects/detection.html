Motorcycle Helmet Detection

OVERVIEW

About the Project

This project focuses on detecting helmet usage among motorcycle riders using YOLOv8n, a lightweight object detection model. The system analyzes images or video frames to identify helmet usage, demonstrating the application of computer vision for road safety monitoring.

MY CONTRIBUTION

What I Worked On

I worked on implementing an object detection model using YOLOv8n to identify helmet usage among motorcycle riders.

The project involved applying computer vision and deep learning concepts while collaborating with team members to develop and refine the solution.
