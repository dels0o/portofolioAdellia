OVERVIEW

About the Project

Lost & Found DApp is a decentralized application designed to support the reporting and tracking of lost and found items using blockchain technology. The project uses smart contracts to manage records on the blockchain, exploring how decentralized systems can improve data transparency and integrity.

MY CONTRIBUTION

What I Worked On

I worked on developing and testing the smart contract using Solidity and Foundry in a local Ethereum development environment. Through this project, I gained practical experience in smart contract development and the implementation of blockchain-based applications.

This project strengthened my understanding of blockchain development, problem-solving, and collaboration in translating project requirements into a functional application.
